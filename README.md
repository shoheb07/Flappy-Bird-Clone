# Flappy-Bird-Clone
Flappy Bird Clone is a 2D arcade game where the player controls a bird and navigates through gaps between moving pipes. The objective is to survive as long as possible and achieve the highest score.

Flappy Bird Clone

Overview

Flappy Bird Clone is a Python game built using Pygame where players control a bird and avoid obstacles by flying through pipe gaps.

The game focuses on timing, reflexes, and score improvement.

Features

* Bird physics
* Gravity simulation
* Random obstacles
* Collision detection
* Live score tracking

Technologies Used

* Python
* Pygame

Installation

pip install pygame

Run Project

python flappy_bird.py
